# Learning Net WordPress Theme

Custom WordPress theme for [The Learning Net](https://thelearningnet.org) — 1-to-1 online tuition (KS2 to A-Level), UK.

## About
Hand-built custom theme (v1.0.2) matching the finalized site design exactly — no page builder dependency for core templates. Currently live on thelearningnet.org.

## Design tokens
- Primary green `#006f60`, ink `#102422`, muted `#526663`, page bg `#f7faf8`
- Accent gold `#f5c64f`, mint `#dff4ea`
- Body: DM Sans, Headings: Manrope

## Templates
- `front-page.php` — homepage with hero, programmes, reviews, FAQ
- `page.php`, `single.php`, `home.php` (blog), `404.php`
- `page-student-login.php` — dedicated student login layout
- `page-blog.php` — blog index
- `header.php` / `footer.php` — sticky nav, mega menu, footer

## Requirements
- WordPress 6.0+, PHP 7.4+
